# Personal screening links

Each file in this folder is **one person's access key**.

- The file name (without `.json`) **is** the secret key. It goes in the link after the `#`:
  `watch.html#<file-name-without-json>`
- The file contents say which video that key unlocks.
- There is intentionally **no index file** listing all keys, so keys can't be discovered by browsing.

## Add a link
Use `watch-admin.html` to generate a key + link, download the `.json` file here, and commit it.
Then send that person their link.

## Revoke a link
Delete that person's `.json` file and redeploy. Their link stops working immediately.

## Notes
- `EXAMPLE-demo-link-delete-me.json` is a demo. **Delete it before publishing** — anyone who
  knows the file name can watch its video.
- Real keys generated by the admin tool are long and random (unguessable).
- This is privacy-by-unguessable-link: the video files themselves are not encrypted, so treat
  the raw `assets/secret-media/...` paths as sensitive too, and don't link to them elsewhere.
